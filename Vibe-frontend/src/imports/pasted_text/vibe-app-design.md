Design a polished, modern iOS mobile app called “Vibe.”

Vibe is a friendship-focused social app that combines dating-app-style discovery with activity-based socializing. The purpose is to help people find friends they genuinely connect with and give them opportunities to meet and do things together in real life.

CORE PRODUCT CONCEPT:

Vibe has two primary ways to connect:

1. VIBES
Users browse potential friends using a Tinder-inspired swipe interface. Users see profiles based on shared interests, personality, social preferences, and activities. Swipe left to pass and right to connect. When two users connect, they become a “Vibe.”

2. ACTIVITIES
Users can browse activities that people are openly looking for others to join. Users can create activities such as pickup basketball, studying, gaming, going to a concert, getting coffee, going to the gym, attending a car meet, etc. Activities should show the activity, date/time, location, number of participants, description, and a Join button.

IMPORTANT PRODUCT PHILOSOPHY:

Vibe is NOT a dating app.
Vibe is NOT an Instagram-style social media feed.
Vibe is NOT focused on followers, likes, or maximizing screen time.

The core philosophy is:
“Find your people. Do something together.”

The app should encourage users to move from:
DISCOVER → CONNECT → CHAT → MEET → FRIENDSHIP

And also:
ACTIVITY → JOIN → MEET PEOPLE → CONNECT

DESIGN STYLE:

Create a dark, premium, modern, energetic visual identity.

The interface should be predominantly dark with near-black backgrounds and deep purple surfaces.

Primary colors:
- Near-black: #0B0910
- Dark purple: #120D1C
- Card background: #1A1426
- Elevated card: #241A35
- Deep violet: #6D28D9
- Bright violet: #8B5CF6
- Vibe orange: #FF7A30
- Bright orange: #FF9A4D
- Primary text: #F5F3F7
- Secondary text: #A8A0B5

The signature Vibe gradient should transition:
ORANGE → PINK → PURPLE → BLUE-VIOLET

Use the gradient sparingly for important actions, branding, compatibility indicators, active states, and major moments.

Do NOT make every screen brightly colored.
Approximately 70% of the interface should be dark neutral colors, 20% purple, and 10% orange/gradient.

Use subtle purple/orange ambient glows and gradients rather than large colorful backgrounds.

The overall feeling should be:
- Modern
- Social
- Premium
- Energetic
- Welcoming
- Young adult / college-friendly
- Sophisticated
- Not childish
- Not overly corporate
- Not like a dating app

Use clean Apple-style typography, generous spacing, rounded cards, subtle shadows, and smooth animations.

APP ICON:

Use the provided Vibe app icon as the visual inspiration for the color palette and brand identity. The icon uses a deep purple background with a warm orange/pink/purple gradient V symbol.

NAVIGATION:

Create a bottom tab bar with four sections:

1. Vibes
2. Activities
3. Chats
4. Profile

Use simple, clean icons. The selected tab should use the Vibe gradient or bright purple/orange accent while inactive tabs remain muted.
