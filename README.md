# Vibe

Vibe is a full-stack social platform designed to help people build genuine friendships and discover activities to do together.

## Project Structure

- `Vibe-frontend/` — React + TypeScript frontend
- `Vibe-backend/` — FastAPI + PostgreSQL backend

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- Alembic

### Security
- JWT authentication
- Argon2 password hashing
- Protected API endpoints

## Current Features

- User registration and login
- JWT authentication
- User profiles
- Interest selection
- Persistent profile data
- Persistent account settings
- REST API integration
- PostgreSQL database persistence
- Database migrations with Alembic

## In Development
